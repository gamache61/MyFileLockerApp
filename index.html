File Locker

Protect your files from accidental deletion with a password.

Download .exe from Actions →

How to download the app

  1. Click the link above to go to the Actions tab
  2. Click the latest green ✅ workflow run
  3. Scroll down and download FileLocker-Windows from Artifacts
  4. Unzip and run FileLocker.exe

Features

🔒

Lock files

Makes files read-only so they can't be edited or deleted accidentally.

🔓

Password unlock

Enter your password to restore full access to your files.

📁

Multiple files

Add as many files as you need to protect at once.

🔑

Change password

Update your password anytime from within the app.

Built with Python + tkinter · Windows only
